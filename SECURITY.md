# Security Policy

## Supported versions

The project currently supports the latest main branch and the latest published release.

## Reporting a vulnerability

Please report security issues privately by opening a GitHub security advisory or contacting the maintainer through the project’s official public channels.

Do not disclose the issue publicly until a fix is available.

## Response expectations

Security reports will be reviewed as quickly as possible, and the maintainers will coordinate remediation and disclosure as appropriate.
